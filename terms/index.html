Condiciones de uso

Fecha de entrada en vigor: 7 de noviembre de 2026

Estas condiciones se aplican a la web de Trading Busters y a la app Trading Busters Publisher. Al usarlas aceptas estas condiciones.

El servicio

Trading Busters Publisher es una herramienta interna que usa el equipo de Trading Busters para publicar nuestros propios vídeos en nuestro propio canal de YouTube y en nuestras cuentas de TikTok, Instagram y Facebook. No tiene usuarios externos; el acceso está limitado a miembros autorizados del equipo.

Servicios de terceros

La app usa los servicios de la API de YouTube, la Content Posting API de TikTok y la Graph API de Meta. Su uso también está sujeto a las condiciones de servicio de YouTube, la política de privacidad de Google, las condiciones de servicio de TikTok y las condiciones de la plataforma de Meta.

Uso aceptable

No puedes usar la app para subir contenido sobre el que no tengas derechos, para incumplir las políticas de una plataforma ni para acceder a cuentas o datos que no sean tuyos.

Contenido

Cambios y terminación

Podemos cambiar estas condiciones o dejar de ofrecer la app en cualquier momento. Los cambios se publicarán en esta página.

Ley aplicable
